# Kompleksitas-dan-Rancangan-Resume-Medis-Tidak-Terstruktur
Analisis Kompleksitas dan Perancangan Pipeline Ekstraksi Entitas Klinis pada Resume Medis Tidak Terstruktur Berbasis NLP/LLM
Sekitar 70–80% data Rekam Medis Elektronik (EHR) di rumah sakit tersimpan dalam bentuk teks bebas tidak terstruktur (seperti CPPT dan resume medis). Saat ini, konversi catatan klinis tersebut ke dalam kode standar internasional (ICD-10/ICD-9-CM) untuk klaim BPJS Kesehatan dan integrasi SATUSEHAT Kemenkes masih dilakukan secara manual oleh medical coder, yang memakan waktu lama serta rentan memicu human error dan pending claim. Repositori ini menghadirkan solusi pipeline Clinical NLP/LLM untuk mengotomatisasi de-identifikasi privasi (UU PDP), ekstraksi entitas klinis, deteksi negasi, hingga serialisasi ke standar HL7 FHIR R4.
